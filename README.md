# Planetarium XL - mises a jour

Firmwares **chiffres et signes** du Planetarium XL (gamme LATTICE, ESP32-S3, ecran rond 360x360).
Inutilisables sans la cle de l appareil : l installation se fait depuis le portail du planetarium (Mise a jour > Depuis un serveur).

Manifeste : `https://github.com/Sufenstyle/planetarium-xl-updates/releases/latest/download/manifest.json`
